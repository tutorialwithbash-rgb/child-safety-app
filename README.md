# Child Safety App

A simple landing page for downloading the Child Safety app. The page includes
the app logo and links to the browser version.

## Development

Install dependencies with Bun:

```sh
bun install
bun run dev
```

Or use npm:

```sh
npm install
npm run dev
```

## Build and test

```sh
bun run build
bun test
```

## Deployment

Pushing to `main` builds and deploys the static site to GitHub Pages using the
workflow in `.github/workflows/deploy.yml`.

https://tutorialwithbash-rgb.github.io/child-safety-app/
